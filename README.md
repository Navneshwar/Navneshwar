## 🧪 Things I've been cooking

<details open>
<summary><b>🐧 ZeroTrace — Linux Security XAI</b> · Python / Linux / eBPF / ML</summary>
<br>
An AI-assisted Linux security project for behavioral threat detection with explainable security insights.

- Processes **30 behavioral features**.
- Uses bounded executable and temporal baselines (4,096 and 8,192 entries).
- Recorded **0.156 ms mean** and **0.333 ms P99** selected-model inference latency per case, with **6.16 MiB** of bounded baseline state.

*The goal: catch weird behavior and have a decent explanation ready when someone asks, “Okay, but why?”*
</details>

<details open>
<summary><b>🧩 EXT4 Deleted File Recovery Workbench</b> · Python / EXT4 / pytsk3 / FastAPI</summary>
<br>
A forensic workbench for examining EXT4 disk images, recovering deleted-file artifacts, and producing integrity-aware reports.

- EXT4 inode and extent analysis, plus JBD2 journal inspection.
- Artifact and timeline extraction with MBR/GPT partition analysis.
- SHA-256 integrity verification for forensic traceability.

*Deleted doesn't always mean gone. Sometimes it means “please investigate carefully.”*
</details>

<details open>
<summary><b>🛡️ HEIMDALL — Unsupervised IoT Botnet Detection</b> · PyTorch / Autoencoders / GMM / NetFlow</summary>
<br>
An unsupervised anomaly-detection pipeline for spotting IoT botnet activity and behavior changes over time.

| Benchmark | Result |
|:--|--:|
| IoT-23 ROC-AUC | **0.9611** |
| Torii PR-AUC | **0.9899** |
| Improvement over single-autoencoder baseline | **3×** |

Under the hood: multi-branched autoencoder experts, Gaussian Mixture Models, NetFlow/IPFIX, and Kolmogorov–Smirnov drift detection.

*Because “looks kinda sus” deserves a measurable baseline.*
</details>
